# Fórmulas do Viveiro explicadas

Cada documento detalha uma fórmula dos pilares técnicos do [kit de divulgação](../kit-divulgacao.html): o significado de cada símbolo e os valores usados no código, um exemplo numérico resolvido passo a passo, aplicações na vida real, uma atividade prática para aula e os limites declarados.

Todos os modelos do Viveiro são exploratórios: os valores são parâmetros do motor, sem calibração para uma espécie real. Os exemplos numéricos usam esses valores e foram conferidos por script. As aplicações na vida real mostram onde a mesma matemática é usada, não que o simulador reproduza esses sistemas.
