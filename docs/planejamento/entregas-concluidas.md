# Entregas concluídas — referência compacta

[Índice ativo](../cronograma.md). Os mecanismos abaixo são exploratórios;
implementação entregue não equivale a validação científica por espécie.

| Etapas | Entregue |
| --- | --- |
| 0–1 | Terrário 3D, primeira pessoa/duplo clique, navegação social, apoio contínuo, terreno arredondado, TS/Vite |
| 2–4 | Escavação/transporte/erosão/reparo, estoques/lixo/prole/trofalaxia/castas, agentes individuais, reação-difusão, ACO e limiares |
| 5A–6B | Genética, voo/fundação/filhas, odores/território, simbioses e mimetismo |
| 7A–7C | Solo granular, umidade/capilaridade, calor/gases/ventilação e suporte simplificado |
| 8A–8C | RL local, checkpoints/replay, previsão cancelável e avaliação sintética |
| 9–11 | Perfis/proveniência, reservas maternas, tampão físico, naníticas, semiclaustral, maturação/diapausa |
| 12–14 | Seleção local de microclima/câmara, fertilidade/longevidade exploratórias, ritmo e avanço headless |
| P0.1–P0.4 | Licenças/integração, GitHub Pages separado, citação e DOI 0.46.0 conferidos |

| P2.2A/B | CLI, manifestos, aritmética portátil e paridade dos cenários ensaiados |

| P4.1A/P4.2A | Estrutura de contribuições e galeria com dez receitas internas |
