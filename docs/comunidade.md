# Estrutura de contribuição — P4.1A

Implementada em 03/11/2026. A primeira contribuição externa integrada (P4.1B)
ainda é um aceite aberto; tarefas abertas pelo mantenedor não contam como tal.

- [Guia em português](../CONTRIBUTING.md) e [inglês](../CONTRIBUTING.en.md).
- Formulários de defeito, proposta e experimento em .github/ISSUE_TEMPLATE.
- Modelo de PR e links para perguntas/documentação.
- [Discussions](https://github.com/albreis/viveiro/discussions) habilitado no
  repositório já público. Issues continuam habilitadas; visibilidade preservada.
- Rótulos good first issue, documentation e help wanted existentes; experiment
  criado para organizar contribuições de cenários.
- Primeiras tarefas pequenas: [glossário #73](https://github.com/albreis/viveiro/issues/73),
  [roteiro no Firefox #74](https://github.com/albreis/viveiro/issues/74) e
  [CSV em planilha #75](https://github.com/albreis/viveiro/issues/75).

Os formulários usam o [formato oficial do GitHub](https://docs.github.com/en/communities/using-templates-to-encourage-useful-issues-and-pull-requests/syntax-for-issue-forms).
Foram verificados pela análise YAML/Markdown do Prettier e revisão de campos,
IDs, rótulos e vínculos. Conferir o seletor real após integrar na branch padrão.
Nenhuma alteração no modelo, nos saves ou na audiência do Site privado.

## Como contar contribuições

Um cenário/revisão entra no acervo após revisão e PR integrado. Registrar a
proveniência e distinguir equipe de contribuição externa real. Não inventar
usuários, autoria ou validação científica para atingir metas do cronograma.
As primeiras tarefas são convites públicos; nenhum contato direto foi enviado.
